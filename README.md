# JAM SaaS

Application React/Vite de pilotage JAM : projets, tâches, athlètes, sections, imports/exports Excel et tableau de bord configurable.

## Installation sur un autre ordinateur

1. Installer Node.js.
2. Cloner le projet :

```bash
git clone https://github.com/belsamis01-rgb/jam-saas.git
cd jam-saas
```

3. Installer les dépendances :

```bash
npm install
```

4. Lancer l'application :

```bash
npm run dev
```

5. Ouvrir l'adresse affichée par Vite, généralement :

```text
http://localhost:5173
```

## Commandes utiles

```bash
npm run build
npm run preview
```

Les données de test saisies dans le navigateur sont stockées localement dans le navigateur utilisé.
